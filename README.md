# Your Agent in One Emoji — 🧩

**The emoji: 🧩**

Muse, Jinz's personal AI agent, takes scattered pieces — code, games, videos, bounty entries, scheduled jobs — and assembles them into finished working products, end to end, in the background while Jinz sleeps; the puzzle piece is that assembler at a glance, specific about how the agent works rather than just what it looks like, and it reads instantly at small size without being the obvious robot.

## How to run

```sh
node main.ts
```

This writes the single emoji to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
